# 繁體中文翻譯約定

## 資源與結構

[英文資源字典](../en-US/strings.yml)是唯一原文；專案規範請參閱[文件維護指南](../../maintenance.md)。建立新譯本時，將英文檔案完整複製為本目錄的 `strings.yml`，保留首行 `### YamlMime:Resources`，並使用 UTF-8 編碼。後續更新應對照英文變更修訂既有譯文，不要重新覆寫整個檔案。本檔案 `translation.md` 永久保留，不發布至網站。

導覽、章節順序、錨點、連結、格式、程式碼和圖片都在 `locales/` 外統一維護。不要在語言目錄內新增文章、TOC、範本、指令碼或設定。

翻譯僅修改本目錄 `strings.yml` 的值。鍵集合必須與英文完全一致，不得自行新增、刪除或重新命名鍵，包括看似相同或尚未遇到的介面文字。如果原文有問題，請向維護者指出資源鍵及問題，先統一修正英文與共用頁面，再同步譯文。

## 文風與上下文

採用嚴謹、自然的技術教材文風，先說明操作之間的關係，再交代條件與限制。教學保留明確的步驟及可觀察的結果。學術風格不代表必須增加被動句、抽象名詞或長句。

依文章的閱讀順序審校，搭配前後段落、表格與程式碼理解內容。資源鍵只是儲存邊界，不是獨立的翻譯單位。將連結標籤與強調片段放回完整句子，檢查語意與銜接，避免逐詞翻譯和重複要求讀者操作。

標題、介面標籤、首頁可見的簡短介紹與頁尾文案不加句末句號；正文、診斷訊息及無障礙操作說明保留正常標點。每個概念使用一種通行譯法，不只為部分術語附加英文括注。API 識別字、檔名與實際設定項目的名稱保持準確；括號可用於必要解釋，不作為例行的雙語標示。

判斷一句話是否需要保留，應看它是否說明目前操作、設計選擇、可觀察結果或正確使用的條件。刪去未使用功能的羅列、籠統的環境提醒與重複前提。標題及跨樣式的短語也須整體翻譯，不照搬英文語序。首頁標題的 `{accent}` 與 `{lineBreak}` 可依中文調整位置，樣式和換行不能決定語序。正文刪改由維護者先統一更新英文、共用繫結與各語言鍵集合，再同步譯文。

## 文字與預留位置

使用自然、簡潔的臺灣繁體中文，以完整句子或段落為單位翻譯，保留前提、否定、單位、操作順序及生命週期限制。不要逐字拼接譯文，也不要加入原文沒有的技術保證、平台需求、套件版本或版本說明。產品名稱、套件名稱、檔名、C#／Slang 識別項及大小寫保持原樣。

每個資源值都必須是非空字串、純文字，不寫 HTML 或 Markdown。注意 YAML 引號與逸出，避免冒號、井字號或類似數字的值遭到誤解析；必要時使用引號。保留英文鍵的排列順序，方便人工核對。

`{context}`、`{link}` 等具名預留位置可對應共用頁面中的程式碼、連結或強調內容；`{name}`、`{query}`、`{count}` 等介面預留位置也可能由程式填入純文字。不要只憑名稱推斷內容，應查看對應資源在共用頁面或介面中的用途。連結標籤或強調文字若有獨立資源鍵，也需要翻譯。

可以依中文語序移動預留位置，但每個鍵都必須保留原有名稱、大小寫與半形大括號，不新增、刪除或改名。不要用顯示出的 API 名稱、連結文字或範例數字取代預留位置，也不要拆分資源鍵來重組句子。

## API 連結與技術含義

連結由共用頁面維護。正文與表格中明確指向站內 API 的識別項連結至對應型別或成員；變數、參數名稱、範例自訂型別、套件名稱、檔名及沒有本站參考頁面的外部符號維持一般程式碼文字。相同拼寫不代表同一個符號。一般教學程式碼區塊不會自動加入連結。譯者可以移動整個預留位置，但不補寫連結、不修改目標，也不改動共用程式碼及其格式。

若某個 API 沒有產生的參考項目，共用頁面會保留一般程式碼文字，並在附近提供明確的原始碼連結。不要自行改成其他型別或成員的連結。

翻譯時尤其注意以下區別：

- 命令記錄、提交、GPU 執行及完成並非同一步驟。
- 資源用途、記憶體駐留／CPU 存取意圖、紋理佈局與像素格式是不同概念。
- 所有權表示釋放資源的責任；持有控制代碼不等於維持資源存活，提交命令也不會移轉所有權。
- GPU 完成不一定代表暫存的回讀資料已複製至應用程式的 CPU 目標；保留原文關於等待所屬佇列的說明。
- `drawable` 指目前影格的輸出紋理，不一律等同於交換鏈影像；資源檢視與 UI 控制項也須依情境區分。

## 建置與交付檢查

在已具備專案所需 .NET SDK 與 DocFX 的環境中，從儲存庫根目錄執行命令。首次取出儲存庫時，`documents/api/` 的產生中繼資料尚不存在，需要先執行包含 API 擷取的完整建置：

```sh
docfx documents/docfx.json --warningsAsErrors
```

之後，若 API 中繼資料已產生且與目前原始碼一致，僅修改字典時可使用一般建置並預覽：

```sh
docfx build documents/docfx.json --warningsAsErrors
docfx serve documents/_site --hostname 127.0.0.1 --port 8080
```

本語言已註冊，完整字典建置成功後即可使用，無須修改設定。缺鍵、多餘鍵、空值、非字串值或預留位置名稱不符都會使建置失敗。建置不會判斷譯文是否準確或是否仍留有未翻譯的英文，必須人工通讀。

各語言共用頁面路徑，以 `?lang=zh-TW` 選擇語言，切換時保留路徑與錨點。未明確指定語言時，依序採用已儲存的手動選擇、瀏覽器語言偏好、英文。若此譯本尚未發布，或字典載入／頁面資源驗證失敗時，頁面回復為英文，而非逐句混用語言。語言清單依語言代碼排序。

交付前核對鍵與預留位置，並在桌面及 320 像素寬度檢查首頁、Learn 入口、三角形教學、概念頁、範例頁與 API 介面。依初學者的順序通讀教學，檢查術語、按鈕、搜尋、程式碼複製、API 跳轉，以及切換語言後的目前章節位置。識別項、宣告與程式碼仍使用共用原文；僅翻譯字典提供的介面與正文。測試字典及暫存檢查檔案放在儲存庫外，不提交暫代譯文。
