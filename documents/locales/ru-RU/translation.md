# Правила перевода на русский язык

## Ресурсы и структура

Английский — единственный исходный язык. Скопируйте только ключи и значения из `locales/en-US/strings.yml` в собственный `strings.yml`. До перевода сохраняйте лишь этот постоянный файл `translation.md`, который не публикуется. Сохраните первую строку `### YamlMime:Resources`.

Навигация, порядок глав, якоря, ссылки, форматирование, код и изображения общие и находятся вне `locales/`. Не добавляйте в этот каталог статьи, TOC, шаблоны, сценарии или настройки.

Ключи обозначают устойчивые роли и понятия. Не переименовывайте их при редактировании формулировок; избегайте имён, зависящих от текста, позиции, нумерации или языка. Переводите только английские значения ясным техническим русским языком.

Значения — обычный текст, не HTML и не Markdown. Именованные параметры, например `{context}` и `{link}`, вставляют общие элементы кода и ссылки. Их порядок можно менять, но все имена должны сохраняться. Не добавляйте и не удаляйте параметры. Обязательны все английские ключи; отсутствие ключа или несовпадение параметров приводит к ошибке сборки.

Используйте прежние команды DocFX. Полный словарь автоматически делает язык доступным. Пути страниц одинаковы для всех языков; `?lang=ru-RU` выбирает язык. Списки языков сортируются по коду каталога.

```sh
docfx documents/docfx.json --warningsAsErrors
docfx serve documents/_site --hostname 127.0.0.1 --port 8080
```

## Терминология

| Английский термин | Принятый вариант |
| --- | --- |
| API / GPU / RHI | Сохранять сокращения и пояснять их по оригиналу |
| barrier | барьер |
| buffer | буфер; `Buffer` не изменять |
| command buffer | командный буфер |
| command queue | очередь команд |
| drawable | текущее изображение для представления; `Drawable` не изменять |
| graphics context | графический контекст |
| pipeline | конвейер |
| readback | считывание данных с GPU |
| render pass | проход рендеринга |
| resource | ресурс |
| shader | шейдер |
| swap chain | цепочка обмена |
| texture | текстура |
| timeline | временная шкала |
| upload | загрузка данных на GPU |
